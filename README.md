# backup-tool

PC 内のファイルバックアップに使うツールリポジトリ。

## 実行・編集

- `backup.bat` のバックアップ対象・保存先・除外設定を編集して実行します。
- バッチファイルは **UTF-8（BOM なし）、CRLF** で保存してください。実行時に `chcp 65001` で日本語表示を揃えます。
- 日時取得には Windows 標準の PowerShell を使います（WMIC 不要、プロファイル読み込みなし）。
- `/MIR` により、コピー元で削除したファイルはバックアップ先でも削除されます。
- 既存の `backup_log.txt` は追記されます。過去の文字化けした内容は修復されません。
